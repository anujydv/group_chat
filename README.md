# Chat App

### Description
> A real-time group chat app. Anyone can create a group, and others can join it by name. A group stays private until someone shares its name.

### Build stack
  * Node.js
  * socket.io
  * HTML and CSS

### How to set up the environment
  * `cd group_chat`
  * `npm i`
  * `npm run start`
  * Open `http://localhost:3000`
